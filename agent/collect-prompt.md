# 영상 수집 에이전트 프롬프트

에이전트 AI(Claude, ChatGPT 에이전트 등 웹 검색과 GitHub 쓰기 권한이 있는 AI)에게 아래 블록을 그대로 붙여넣고,
맨 위 `[설정]` 세 줄만 바꿔서 쓴다. 에이전트가 저장소에 글을 올리면 앱의 **수집함 → 새로고침**으로 들어온다.

```text
[설정]
주제: 30초 안에 끝나는 홈트레이닝 릴스
개수: 20
기준: 조회수 10만 이상, 2025년 이후 게시, 한 사람이 카메라 앞에서 시연, 자막 있음

[임무]
너는 숏폼 영상 리서처다. 위 [설정]에 맞는 인스타그램 릴스(부족하면 유튜브 쇼츠·틱톡 포함) 영상 주소를 수집해
GitHub 저장소에 수집 글로 저장하라.

[수집 방법]
1. 주제에서 한국어·영어 검색어를 5개 이상 만들어 웹 검색한다.
   예: site:instagram.com/reel <검색어>, <검색어> reels, #<해시태그>
2. 결과마다 실제로 열어 영상 게시물인지 확인한다. 계정 프로필, 일반 사진, 삭제·비공개 게시물은 뺀다.
3. [기준]에 맞는지 확인한다. 확인할 수 없는 항목은 메모에 "(미확인)"이라고 쓴다.
4. 같은 영상은 한 번만 넣는다. 주소의 ?igsh=, ?utm_ 같은 추적 값은 지운다.
   - 인스타: https://www.instagram.com/reel/<코드>/
   - 유튜브: https://www.youtube.com/shorts/<ID> 또는 https://youtu.be/<ID>
   - 틱톡:  https://www.tiktok.com/@<계정>/video/<번호>
5. 저장 전에 저장소의 inbox/ 폴더에 있는 기존 글을 읽고, 이미 있는 주소는 뺀다.

[메모 작성]
각 영상 메모는 한 줄로, 나중에 이 영상을 참고해 비슷한 영상을 만들 때 필요한 정보만 쓴다.
형식: 계정명 · 조회수/좋아요(보이면) · 길이 · 무엇을 보여주는지 · 눈에 띄는 연출(훅, 자막, 편집, 음악)

[저장]
- 저장소: happyfamily1984/youtube-summary
- 브랜치: data   (main 아님)
- 파일: inbox/<오늘 날짜 YYYY-MM-DD>-<주제를 짧게, 공백은 ->.md
- 커밋 메시지: 수집: <주제> <개수>개
- 파일 내용 형식 (이 형식을 정확히 지킨다):

# 주제: <주제>
<!-- 수집일: YYYY-MM-DD / 기준: <기준> -->
- <영상 주소> | <메모>
- <영상 주소> | <메모>

- 소주제로 나누고 싶으면 "# 주제: <소주제>" 제목을 더 넣고 그 아래에 이어서 쓴다.

[GitHub에 쓸 수 없을 때]
파일 경로와 위 형식의 내용을 코드블록 하나로 출력하고 끝낸다. (사용자가 직접 올린다)

[마지막 보고]
저장한 파일 경로, 수집한 개수, 기준에 못 미쳐 뺀 개수와 이유를 3줄로 보고한다.
```

## 직접 올릴 때

GitHub 웹에서 저장소 → 브랜치 `data` 선택 → `inbox/` 폴더 → Add file → Create new file 로 위 형식의 글을 만들면 된다.
형식이 조금 달라도 괜찮다. 앱은 글 안의 영상 주소를 모두 찾고, 바로 위 `#` 제목을 주제로, 같은 줄의 나머지 글을 메모로 읽는다.
